# RimWorld Flat Layout Reference Pack

Retrieved: 2026-05-25

This folder is a local, source-attributed image pack for studying normal
RimWorld base layouts. It is reference material for Willie
layout-pattern mining, not a design contract by itself.

## Contents

- `full-base/` - 100 colony-scale layouts, favoring normal flat/open-map bases.
- `single-room/` - 66 room, module, and defensive layout references.
- `manifest.csv` - source page, image URL, source name, title, score, and byte
  count for every retained image.

## Scope

The collection intentionally filters out mountain bases, sea ice / ice sheet
bases, spaceship / gravship / orbital bases, and obvious special-mode or
heavily mod-specific layouts. The filtering is title/source based, so treat the
pack as a first-pass reference set and delete weak images as they are found.

Single-room references are separated because they support different questions
than full-base references: freezer/kitchen adjacency, hospital shape, bedrooms,
prisons, workshops, hydroponics, stockpiles, and killbox modules.

## Source Policy

Sources are mixed: existing repo guide-corpus images, RimWorld Base pages,
RimWorld Wiki-derived images already in the corpus, and community Reddit image
posts. Reddit images are saved from preview-sized URLs to keep the pack usable.
Licenses vary. Use these as local, source-attributed research references; check
the original source and license before redistributing images publicly.

For durable RimBob behavior, promote only synthesized heuristics into
`.plans/base-layout-construction-tips.md` or
`Docs/design/ministers/construction.md`.
