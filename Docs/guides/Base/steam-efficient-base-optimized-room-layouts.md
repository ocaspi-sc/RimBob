Useful mostly as an inspiration source and a cautionary source. The visible comments and video-only shape make it less authoritative than the wiki, but it captures a common player desire: repeatable room modules that reduce walking and keep the base legible.

## Layout Heuristics

- Treat room layout as workflow design. A pretty room is not optimized if it increases hauling, cooking, tending, or crafting travel.
- Use compact repeatable templates, then verify them against actual RimWorld mechanics.
- Bedrooms should include expected support furniture where the colony can afford it: end table, dresser, light, and optional beauty.
- Greenhouse and hydroponics layouts should be centered around reliable sun-lamp coverage instead of scattered crops.
- Workshops need the complete chain: storage, tailoring, stonecutting, crafting, research, and shared tool-cabinet coverage.
- Tool cabinets are valuable when one cabinet supports several eligible benches.
- Hospitals should prioritize clean access, medicine proximity, bed reachability, and minimal wasted floor area.
- Dining and rec rooms can use shared impressiveness, but expensive flooring can be poor value if it bloats wealth without solving the lowest room stat.
- Validate any guide template against adjacency, cleanliness, light, building coverage, and movement cost before promoting it to a rule.
- Treat video thumbnails as weak evidence. They identify the source but do not replace a readable floor-plan artifact.
