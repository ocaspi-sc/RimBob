Ministers are decoupledCoupling

Direct minister-to-minister calls create ordering and recursion problems. Flags on the advice bus let them communicate without knowing about each other.

Briefings hold derived facts onlyPrompts

Raw game state in a prompt inflates token cost and confuses the model. Briefings pre-compute the facts that matter — food days, threat level, worker gaps.

Rules before LLM, alwaysCost

Most ticks have obvious answers a rule can emit in <1 ms. Reserving the LLM for genuine ambiguity cuts API spend and makes advice predictable.

RAG over fine-tuningKnowledge

The RimWorld corpus changes when guides are updated. Retrieval keeps knowledge current without retraining; citations let players spot outdated snippets.

Append-only replay corpusSafety

Refinements must be testable against real history. Mutating the log would invalidate that signal, so writes are append-only and deletions are forbidden.

Versioned snapshots, not diffsState

Diffs are hard to replay and easy to corrupt. Full versioned snapshots are slightly larger but make any point-in-time state trivially reconstructable.
